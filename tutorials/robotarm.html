Robot Arm Control Lesson

Posted 24/04/2026

In this tutorial we will be using Mujoco, a simulator developed by Google Deepmind. The repository also supports PyBullet, however this tutorial focuses on the Mujoco as it is easier to install. This tutorial is also aimed at Windows users, though everything other than the setup works for Linux. Controlling robotic arms is considered a solved task, using methods like inverse kinematics which calculates the required movements in each joint for a target coordinate. This simulation has this all solved, all you need to do is make use of existing commands to control the robot. The first task is to get an understanding of how the robot arm can be controlled, then we lead on to autonomous problem solving. We employ the use of a large language model that has pretrined knowledge we can make use of. Of course, large language models have their limitations, but for the sake of this educational task we can make use of the problem solving abilities of a large language model.

Loading the Simulation and Controlling the Robot

We load the simulation by creating the environment as an object. If you get errors in the worksheet saying that there is no path or directory found, you will need to make sure the path is to the the folder "kuka_iiwa_14/" which you downloaded from our GitHub in the setup. I have called this PATH_TO_FILE in the code below: 

e=Env(PATH_TO_FILE)
viewer=mujoco.viewer.launch_passive(e.model, e.data)
e.setViewer(viewer)
This will bring up the window with the robot arm.

You can start to move this arm around by using the command to move_gripper_to and the parameters of the coordinates where you want the hand part to be. The code line below calculates the gripper movements needed to x coodirnate 0.4, y 0.5 and z 0.1. In order to make it actually move we must use the step function to catch the simulator up. 

e.move_gripper_to([0.4,0.5,0.1])
e.step()


We can then add objects to the simulation using commands such as: 
e.generate_blocks(5)
e.update_task()
For generating 5 blocks we can use the generate_blocks but if you wanted to be specific about a block and its creation you can use the following: 

position=[0.4,0.5,0.05]
colour=[1,0,0,1] 
size=[0.02,0.02,0.02]
e.generate_block(position,colour,size)
e.update_task()
Always end with the update_task function to make sure that the simulator loads in the changes. To remove everything you can use e.reset(). Lets see an example, the below code generates three blocks of varying colours and sizes. 

e.generate_block([0.4,0.5,0.05],[1,0,0,1],[0.02,0.02,0.02])
e.generate_block([0.6,0.4,0.05],[1=0,1,0,1],[0.04,0.04,0.04])
e.generate_block([0.7,0.3,0.05],[0,0,1,1],[0.02,0.02,0.1])
e.update_task()


Finally, we can observe all information from the environment by using the get_observation function. It returns a distionary datatype with keys for blocks, colours and sizes. Each index in the array represents the information for that number block. 

dictionary=e.get_observation()
print("Block coordinates:",dictionary['blocks'])
print("Block colours:",dictionary['block_colours'])
print("Block sizes:",dictionary['sizes'])

print("All data items",list(dictionary.keys()))

Task Solving

Lets focus on task 1, the task is to generate a number of blocks, loop through and pick them up one by one. Like all algorithms, we need to break down the steps to solving the problem.

1) Generate the blocks
2) Pick a target location to stack the blocks
3) Then loop through each block, pick it up and drop it in the target location

Using the various commands we mentioned above, we can firstly generate our blocks. We can also pick a target location with an array This can be anything, I have chosen (0.5,-0.5,0.2). 

e=Env(PATH_TO_FILE)
viewer=mujoco.viewer.launch_passive(e.model, e.data)
e.setViewer(viewer)
e.generate_blocks(4)
e.update_task()
# target location 
target_location=[0.5,-0.5,0.2]

We then can loop through each of the blocks using the observe function, and pick one by one. 

obs=e.get_observation()
for i in range(len(obs["blocks"])):
	location=obs["blocks"][i]
	colour=obs["block_colours"][i] #not needed for this task
	sizes=obs["sizes"][i] #not needed for this task

	location[2]=location[2]+0.05 #move slightly above the block so it does not topple it
	e.move_gripper_to(location) #move to block
	e.step(100) #update
	e.pick_block() #place block down
	e.step()

	e.put_block() #drop the block
Now this will move the arm to each of the blocks, pick it up, but then immediatly drop it again as seen in the use of the command put_block. You will need to put code imbetween these instructions to move the arm to the target position.
